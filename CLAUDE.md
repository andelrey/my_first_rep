# The Second One — правила для Claude Code

Прототип мобильной гонки «приедь вторым» (Phaser 3 + Vite) лежит в `game-prototype/`.
Рабочая ветка: `claude/the-second-one-prototype-r9ymut`.

## Перед работой
Прочитай `game-prototype/docs/DEVLOG.md` целиком — там текущее состояние, история
решений и план. Спорные вопросы решай по `game-prototype/docs/decisions.md` (приоритетный).

## Журнал разработки — обновлять автоматически
После **каждого** изменения кода, баланса или трассы, в том же коммите, обнови
`game-prototype/docs/DEVLOG.md`:
- добавь запись в «6. История изменений»: дата, что и **почему** изменено (какое
  замечание или проблема), результат проверки (сборка, бот-тестер), отступления от брифа;
- поправь «5. Текущая модель гонки», если изменились механики или параметры;
- обнови статусы в «8. План» и раздел «9. Дальше»;
- обнови дату «Последнее обновление» вверху.
Хеш коммита в запись можно не вписывать (он появляется только после коммита).

## Правила проекта
- Все числа — в `game-prototype/src/config.js`, трасса — в `game-prototype/src/level.js`.
- Не переписывать архитектуру без нужды. Не добавлять события, урон, банды, экономику,
  другие миры — это фаза беты.
- Названия в игре обобщённые, без реальных городов, артистов и брендов.
- Проверка перед коммитом: `npm run build` в `game-prototype/`; для баланса —
  `node tools/playtest.mjs <gas|skill|none> 3` при запущенном `npm run dev`.
- Общение с пользователем — на русском.
