# The Second One — прототип ядра

Вертикальный срез по `docs/prototype-brief.md`: одна трасса «Качели», удержание
второго места. Модель прототипа — машины едут по сплайну (рельс), игрок управляет
**темпом** (газ/дрифт) и **боковым смещением** (руль). Позиция считается по
прогрессу вдоль трассы.

## Запуск
```
npm install
npm run dev      # http://localhost:5173
```

## Управление
- **Газ** — правая кнопка на экране / клавиша ↑ (или Space, W). Отпустил — плавно тормозишь.
- **Руль** — наклон телефона (в браузере на десктопе — ← / →). Руль нужен, чтобы
  встать в **поток** (хвост) машине впереди или выйти из него.
- **Дрифт** — пока выключен (`driftEnabled: false`): по GDD §10 он открывается на
  уровнях 4–5 вместе с трассой с явными поворотами.

## Как устроена гонка
- **Поток (слипстрим):** в хвосте у машины впереди — +12% к потолку скорости. Без
  потока игрок медленнее чемпиона на прямых. Конус за машиной светлый — ты в потоке;
  красный — ты уже быстрее её и сейчас обгонишь. Красный конус за тобой — кто-то сидит
  у тебя в хвосте. Вышел из потока — набранная скорость гаснет плавно («рогатка»).
- **Тяжесть лидерства** (всем машинам): первому тяжелее разгоняться.
- **Чемпион** силён на прямых (синие зоны), слаб в поворотах (красные). Финиш — поворотом:
  на газу вылетишь первым.
- **Среднячки** медленнее игрока, но в финишной зоне разгоняются и давят снизу: отпустил
  газ слишком рано — уехал третьим.

## Что крутить
Все параметры — в `src/config.js` (скорости, окно серебра, тяжесть лидерства,
сила дрифта, финишная зона, пороги звёзд). Трасса — в `src/level.js`.

## Журнал разработки
История изменений, текущее состояние и план — в `docs/DEVLOG.md`.

## Структура
- `src/main.js` — конфиг Phaser, сцены.
- `src/config.js` — все крутибельные параметры.
- `src/level.js` — трасса «Качели» (сплайн + красные/синие зоны).
- `src/scenes/GameScene.js` — игровой цикл, ИИ, HUD, финиш.
- `src/scenes/ResultScene.js` — церемония результата.
- `tools/playtest.mjs` — бот-тестер баланса (headless Chromium).

## Вне скоупа прототипа
События, урон, банды, экономика, магазин, другие миры, мультиязычность — по
`docs/decisions.md` это фаза беты/релиза. Прототип проверяет один вопрос:
**удерживать второе место — весело или бесит?**
