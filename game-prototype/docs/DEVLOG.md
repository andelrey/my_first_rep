1. Репозиторий: `andelrey/my_first_rep`, ветка **`claude/the-second-one-prototype-r9ymut`**
   (в `main` прототипа пока нет). Прототип — в подпапке **`game-prototype/`**.


## 2. Запуск

```
cd game-prototype
npm install          # первый раз
npm run dev          # http://localhost:5173
npm run dev -- --host   # чтобы открыть с телефона в той же Wi-Fi-сети
```

Управление на десктопе: газ — ↑ / W / Space, руль — ← / →, дрифт — Shift. На телефоне —
«ГАЗ» справа, «ДРИФТ» слева, наклон (ландшафт).

## 3. Правила проекта (не нарушать)

- Спорное решаем по **`docs/decisions.md`** — он приоритетнее остальных доков.
- Все числа — в **`src/config.js`**, трасса — в **`src/level.js`**. Архитектуру без нужды не переписываем.
- В прототип **не** добавляем: события, урон, банды, экономику, магазин, другие миры,
  мультиязычность — это фаза беты.
- Названия в игре обобщённые: Скандинавская деревня, Фьорды, Океанариум, Музей
  электронной музыки, Скандинавская столица, Автодром. Без реальных городов, артистов, брендов.
- Критерии прототипа (brief §14.1): цель понятна за 10–15 с; рестарты подряд по своей
  воле; игрок может объяснить, почему проиграл; финиш читаем.
- `docs/master-gdd.md` **в репозитории нет** (по HANDOFF.md его экспортируют из
  claude.ai отдельно). Пока опираемся на `mechanics.md` + `decisions.md`.

## 5. Текущая модель гонки

Машины едут по сплайну («рельс»). Игрок управляет темпом (газ) и полосой (руль).
Позиция — по прогрессу вдоль трассы. Сплайн масштабируется так, чтобы гонка шла
`raceLengthSec` ≈ 35 с на базовой скорости.

**Цель модели (формулировка пользователя):** второе место — *узкая полоска неустойчивого
равновесия* у заднего бампера лидера. Её держат три силы, повороты её раскачивают:
поток тянет вперёд (в обгон = позор) → тяжесть лидерства выталкивает назад → хвостист
наказывает за недокат (отпустил газ дольше нужного — третий). «Зажал газ» вылетает из
полоски в любую сторону. Каждая сила — под своим флагом в `config.js`.

| Сила / механика | Как работает сейчас | Флаг и параметры |
|---|---|---|
| Потолок игрока | 300 px/с без потока | `maxSpeed` |
| **Поток** | конус 120 px за машиной впереди (±24 px, не ближе 40 px): +12% к потолку (боты +6%). **Дрифт выводит из конуса** | `slipstream.enabled`, `slipstream.driftExits`, `slipstream.*` |
| «Рогатка» | вышел из потока — лишняя скорость гаснет плавно (40 px/с²) | `slipstream.slingshotDecay` |
| Конусы | светлый — ты в потоке; красный — быстрее впереди идущего (обгонишь); бледно-красный за тобой — кто-то в твоём хвосте | `slipstream.overheatPx` |
| **Тяжесть лидерства** | всем: лидеру разгон ×0.85, потолок ×0.97. **Нервный лидер** (игрок): машину водит по полосе ±16 px и покачивает ±9° | `leaderHeaviness`, `leaderWobble.enabled` |
| **Хвостист** | первый бот в решётке (Свен, ржавый): темп игрока (1.0), сидит в его полосе/потоке. Сам не обгонит, пока ты на газу; сбросил — обошёл. Обогнав игрока — едет обычным среднячком | `tailer.enabled`, `tailer.pace` |
| **Повороты-насос** | красные зоны подсвечены на асфальте (≈0.4 с заранее). Внутри поворота газ разгоняет только до лимита 0.88 базы (~264). **Влетел быстрее лимита — ЗАНОС**: 1 с газ не работает, скорость падает до ~210, выносит наружу, надпись «ЗАНОС». ИИ тормозит до лимита заранее | `corners.enabled`, `corners.*` |
| **Характер чемпиона** | прямые 1.03 (лидируя ≈300 = потолку игрока) ± 3% «дёрганый» темп; **перед поворотом резко бьёт по тормозам** до 0.80 (стоп-сигналы), в повороте 0.86; в финишной зоне 1.06 | `championJitter.enabled`, `champion*Pace` |
| Стоп-сигналы | у всех машин при замедлении > 45 px/с² | `brakeLightDecel` |
| Лидер не уезжает за экран | rubber-band чемпиона **только вне кадра** ×0.92; 2–4 корпуса держатся темпом, не резинкой | `leaderGapCap.enabled` |
| Прожектор | золотой круг + «#1» над текущим лидером; вспышка при смене; пульсирует на игроке; имя лидера в HUD | `spotlight` |
| Среднячки (2 обычных) | 0.90 ± 0.02 базы; ищут поток и обходят вбок; финишная зона 1.02 базы | `botPace*`, `botFinishPace` |
| Rubber-band ботов | только вне кадра: дальше окна серебра от лидера — +8% | `rubberBand`, `silverWindowPx` (200) |
| Финиш | порядок по пересечению, интерполяция в кадре; двое соперников финишировали — конец («отстал»). Трасса кончается поворотом | `level.js` |
| Звёзды | 1★ второе; 2★ второе и ни кадра первым; 3★ второе, ≤ 20 px до лидера | `perfectSilverPx` |
| Дрифт | мягкий (с газом) −12%/с и 25°, резкий (без газа) −35%/с + торможение и 45°; выводит из потока | `driftEnabled`, `drift*` |
| Атаки ботов (шаг 4) | не сделано | — |

4. Чемпион полз весь поворот на 240 при лимите 264 — его обходил весь пелотон → резкий
   тормоз только НА ПОДХОДЕ (0.80), в повороте 0.86.
5. В финише хвостист в потоке (~343) был быстрее всего, что доступно игроку → серебро

6. Занос стоил ~25 px — газовик оставался вторым → занос 1 с до ~210 (~1.5 корпуса).

Итог бот-тестера (по 6 гонок): **gas** — 3-е ×6 (первым 2–9% гонки, в заносе 10–12%);
**none** — 5-е; **skill** (держит полоску: газ, вбок из потока, мягкий дрифт вплотную,
сброс перед поворотом) — 3-е/4-е, **серебро не взял ни разу**. Вторым полоска ~0.2–1 корп.
до лидера и ~0.2–0.4 корп. до 3-го (было 4 и 5–7). Трек показывает, что тестер теряет
место в поворотах: из-за опроса раз в 50 мс входит на ~256 вместо 264, а внутри поворота
все едут на лимите — хвостист, обошедший там, остаётся впереди до конца поворота.
**Риск:** полоска может оказаться слишком узкой и для человека — решает живая игра.
Если серебро недостижимо, крутить по очереди: `tailer.pace` (1.0 → 0.97), `corners.limitPace`
(шире разница с чемпионом), `corners.skidSec`, `slipstream.boost`.

## 7. Как проверять изменения

- `npm run build` — должна собираться без ошибок.
- Бот-тестер (при запущенном `npm run dev`):
  `node tools/playtest.mjs gas 3`, `… skill 3`, `… none 3`.
  Текущие результаты — в последней записи §6. Тестер печатает долю времени первым / в потоке /
  в заносе и медианные разрывы вторым (до лидера и до 3-го, в корпусах).
  Тестер опрашивает игру раз в 50 мс — это грубое приближение игрока, окончательно
  баланс решается на ощущениях.
- Подвох, на котором уже спотыкались: `import('/src/main.js')` со страницы после
  правок создаёт **вторую** копию игры — тестер берёт URL модуля из `performance`.

## 8. План

### 8.1 Настройка ядра (текущий приоритет, план пользователя)
Строго по одному изменению; каждый шаг — за своим флагом; после каждого шага
пользователь играет сам и отвечает на вопрос шага. Если на каком-то шаге «ок» — стоп.

| Шаг | Что | Флаг | Вопрос к игре | Статус |
|---|---|---|---|---|
| 0 | Чистая база: вернуть дрифт. Больше ничего | `driftEnabled` | Ядро правда пустое или это был артефакт? | ✅ ответ: пустое («отпускай газ периодически, повороты не нужны») |
| 1 | Поджать разрыв до лидера: rubber-band **только вне кадра** (§4.5) держит лидера в ~2–4 корпусах, всегда на экране. Слипстрим рабочий (конус за лидером тянет), **дрифт выводит из конуса**. Пелотон и чемпиона не трогать | `leaderGapCap`, `slipstream` on/off | Сидеть за лидером стало страшно (тянет в обгон = позор)? Резинка не читается как «магнит»? Критерий: подъезд к лидеру — риск, а не нейтрально | ✅ сделано (`slipstream.enabled`, `slipstream.driftExits`, `leaderGapCap`), ждёт игры |
| 2 | Характер чемпиона (если за лидером всё ещё уютно): дёрганый темп, резче тормозит перед поворотами, сильнее сброс в красных зонах — проваливается тебе в нос. Торможения телеграфировать стоп-сигналами | `championJitter` | Нельзя сесть на бампер и уравнять скорость? «Влетел в зад» не ощущается несправедливым? | ✅ сделано (`championJitter`, `corners`), ждёт игры |
| 3 | Поджать пелотон (если сзади мёртво): сузить нижнюю половину окна серебра ИЛИ один «хвостист», давящий на задний бампер. Скоростью ботов не читерить — ширина окна (§4.1) | `packSqueeze` | Давление сзади заставляет нырять в поток лидера (в зону риска)? | ✅ сделано как хвостист (`tailer`) + нервный лидер (`leaderWobble`), ждёт игры |

## 9. Дальше

Пользователь играет модель равновесия и отвечает на вопросы шагов 1–3 (§8.1). Главный
вопрос: **достижимо ли серебро** — бот-тестер его не взял. Если ощущения спорные — выключать
силы по одной флагами (`leaderWobble`, `tailer`, `corners`, `championJitter`,
`slipstream.driftExits`) и смотреть, какая ломает/делает игру. Шаг 4 (атаки ботов) — только
когда 1–3 дадут живой двусторонний зазор.
