# The Second One — журнал разработки прототипа

_Живой документ для передачи в другой чат или проект. Обновляется после каждого
изменения (правило — в `CLAUDE.md` в корне репозитория). Последнее обновление: 2026-09-26._

## 1. Как продолжить в новом чате

1. Репозиторий: `andelrey/my_first_rep`, ветка **`claude/the-second-one-prototype-r9ymut`**
   (в `main` прототипа пока нет). Прототип — в подпапке **`game-prototype/`**.
2. Дать новому чату промт:

```
Ты — гейм-разработчик на Phaser 3 + Vite. Продолжаем прототип The Second One.
Репозиторий andelrey/my_first_rep, ветка claude/the-second-one-prototype-r9ymut,
прототип в game-prototype/. Сначала прочитай game-prototype/docs/DEVLOG.md целиком
(состояние, история решений, план), затем docs/decisions.md (приоритетный),
prototype-brief.md, mechanics.md, concept-and-plan.md. Продолжай с раздела
«Дальше» DEVLOG. После каждого изменения обновляй DEVLOG.md.
```

## 2. Запуск

```
cd game-prototype
npm install          # первый раз
npm run dev          # http://localhost:5173
npm run dev -- --host   # чтобы открыть с телефона в той же Wi-Fi-сети
```

Управление на десктопе: газ — ↑ / W / Space, руль — ← / →, дрифт — Shift. На телефоне —
«ГАЗ» справа, «ДРИФТ» слева, наклон (ландшафт).

## 3. Правила проекта (не нарушать)

- Спорное решаем по **`docs/decisions.md`** — он приоритетнее остальных доков.
- Все числа — в **`src/config.js`**, трасса — в **`src/level.js`**. Архитектуру без нужды не переписываем.
- В прототип **не** добавляем: события, урон, банды, экономику, магазин, другие миры,
  мультиязычность — это фаза беты.
- Названия в игре обобщённые: Скандинавская деревня, Фьорды, Океанариум, Музей
  электронной музыки, Скандинавская столица, Автодром. Без реальных городов, артистов, брендов.
- Критерии прототипа (brief §14.1): цель понятна за 10–15 с; рестарты подряд по своей
  воле; игрок может объяснить, почему проиграл; финиш читаем.
- `docs/master-gdd.md` **в репозитории нет** (по HANDOFF.md его экспортируют из
  claude.ai отдельно). Пока опираемся на `mechanics.md` + `decisions.md`.

## 5. Текущая модель гонки

Машины едут по сплайну («рельс»). Игрок управляет темпом (газ) и полосой (руль).
Позиция — по прогрессу вдоль трассы. Сплайн масштабируется так, чтобы гонка шла
`raceLengthSec` ≈ 35 с на базовой скорости.

**Рычаги, которые делают место управляемым:**

| Механика | Как работает | Параметры |
|---|---|---|
| Потолок игрока | 300 px/с без потока — медленнее чемпиона на прямых | `maxSpeed` |
| Поток (слипстрим) | в конусе 120 px за машиной впереди (±24 px по полосе, не ближе 40 px) потолок +12%. Боты используют хуже: +6% | `slipstream.*` |
| «Рогатка» | вышел из потока — лишняя скорость гаснет плавно (40 px/с²), можно обойти сбоку | `slipstream.slingshotDecay` |
| Конусы на экране | светлый — ты в потоке; красный — ты быстрее впереди идущего (сейчас обгонишь); бледно-красный за тобой — кто-то у тебя в хвосте | `slipstream.overheatPx` |
| Тяжесть лидерства | всем машинам (decisions №2): лидеру разгон ×0.85, потолок ×0.97 | `leaderHeaviness` |
| Прожектор | золотой круг + «#1» над тем, кто первый СЕЙЧАС; вспышка при смене лидера; пульсирует, если это игрок. В HUD — имя лидера | `spotlight` |
| Чемпион | прямые (синие зоны) 1.08 базы, повороты (красные) 0.85; гуляет по полосе ±40 px с периодом 6 с | `champion*` |
| Среднячки | 0.90 ± 0.02 базы; ищут хвост и обходят вбок; в финишной зоне 1.08 базы — давят снизу | `botPace*`, `botFinishPace`, `slipstream.ai*` |
| Rubber-band | только вне кадра: бот дальше окна серебра от лидера получает +8% | `rubberBand`, `silverWindowPx` (200) |
| Финиш | место по порядку пересечения; момент пересечения интерполируется внутри кадра; двое соперников финишировали — гонка заканчивается («отстал») | — |
| Трасса «Качели» | зоны синий/красный чередуются; **финиш — поворотом** (красная зона 0.94–1.00) | `level.js` |
| Звёзды (независимые) | 1★ второе; 2★ второе и ни кадра первым; 3★ второе с разрывом ≤ 20 px до лидера | `perfectSilverPx` |
| Дрифт | мягкий (с газом) −12%/с и 25°, резкий (без газа) −35%/с + обычное торможение и 45°, следы шин. **Включён.** Пока НЕ выводит из потока (это шаг 1 настройки) | `driftEnabled`, `drift*` |

**Задуманная петля:** на прямых без потока чемпион уезжает → нужно встать рулём в хвост;
в хвосте быстрее чемпиона → конус краснеет, надо отпустить газ; в поворотах чемпион
тормозит → на газу вылетаешь первым; в финишной зоне боты разгоняются → рано отпустил —
уехал третьим. Финиш поворотом: «тупо газ» = первое место.

1. Добавлен поток всем поровну → пелотон слипался в точку (5 машин в 32 px), порядок на

2. Бот садился в хвост чемпиону и навсегда занимал второе (318 > потолка игрока 300). →

4. Обгон бота в потоке был невозможен (разница 1–4 px/с). → «рогатка».
5. Боты не давили на финише (их +8% считались от пониженного темпа). → в финишной зоне

6. Финиш сделан поворотом (как в брифе) — чемпион на финише «спасал» газовика.

**Итог (6 гонок на стратегию):** «всё время газ» — 5× первое (позор), 1× серебро;

**Отступления от брифа (осознанные, проверить на ощущениях):** потолок игрока 300

## 7. Как проверять изменения

- `npm run build` — должна собираться без ошибок.
- Бот-тестер (при запущенном `npm run dev`):
  `node tools/playtest.mjs gas 3`, `… skill 3`, `… none 3`.
  Ориентир текущего баланса: gas → чаще первое; skill → чаще второе; none → пятое за ~35 с.
  Тестер опрашивает игру раз в 50 мс — это грубое приближение игрока, окончательно
  баланс решается на ощущениях.
- Подвох, на котором уже спотыкались: `import('/src/main.js')` со страницы после
  правок создаёт **вторую** копию игры — тестер берёт URL модуля из `performance`.

| Шаг | Что | Флаг | Вопрос к игре | Статус |
