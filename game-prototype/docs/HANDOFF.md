# The Second One — передача в разработку (Claude Code)

Положи папку `docs/` из этого архива в корень репозитория `game-prototype`
(рядом уже лежит собранный прототип: `src/`, `index.html`, `package.json`).
Добавь туда же **`docs/master-gdd.md`** — это living-doc «The Second One —
дизайн-документ» из claude.ai (экспортируй его отдельно: в окне документа
есть «скопировать как Markdown» / экспорт). Затем вставь в Claude Code промт ниже.

## Карта файлов

- `docs/concept-and-plan.md` — концепт, рынок, поэтапный план.
- `docs/mechanics.md` — ядровая механика (окно серебра, тяжесть лидерства, заряд,
  дрифт, ИИ, банды, события, урон, перки, правила финиша, миры, дорожная карта).
- `docs/master-gdd.md` — самый полный дизайн-документ (добавить вручную).
- `docs/prototype-brief.md` — бриф на прототип: параметры + JSON трассы «Качели».
- `docs/decisions.md` — зафиксированные ответы на 20 открытых вопросов. **Приоритетный.**
- `docs/setup.md` — стек (Phaser 3 + Vite + Capacitor), запуск.
- `src/` — уже собранный прототип (Vite + Phaser), собирается и запускается.

## Промт для Claude Code

```
Ты — гейм-разработчик на Phaser 3 + Vite. В репозитории уже есть собранный
прототип игры The Second One (см. src/, index.html, package.json) и папка docs/.

Сначала прочитай docs/ целиком: concept-and-plan.md, master-gdd.md, mechanics.md,
prototype-brief.md, decisions.md, setup.md. Спорные места решай строго по
docs/decisions.md — этот файл ПРИОРИТЕТНЫЙ над формулировками в остальных.

Игра: мобильная дрифт-гонка, вид сверху, цель — приехать РОВНО ВТОРЫМ (закон Янте).
Первое = проигрыш («церемония позора»), третье и ниже = «отстал». Гибрид-казуал:
гонка 30–60 с, рестарт в один тап, вся сложность в меню, а не в HUD.

Текущее состояние прототипа: одна трасса «Качели», машины едут по сплайну (рельс),
игрок управляет темпом (газ/дрифт) и боковым смещением (руль наклоном); есть
чемпион + 3 бота, окно серебра, тяжесть лидерства, финишная зона, звёзды,
церемония. Все параметры — в src/config.js, трасса — в src/level.js.

Задача (по шагам, каждый — с проверкой перед следующим):
1. Запусти прототип, прочитай код, кратко опиши, что уже реализовано и где
   параметры. Ничего пока не меняй.
2. Предложи короткий план доводки ядра под критерии из prototype-brief.md §14.1
   (игрок понимает цель за 10–15 с; делает рестарты подряд; может объяснить,
   почему проиграл; финиш читаем). Жди моего ок.
3. По моему выбору дорабатывай по одному пункту, показывая изменения и как это
   проверить в браузере.

Правила: не переписывай архитектуру без нужды; не добавляй события, урон, банды,
экономику, другие миры — это фаза беты по docs/decisions.md, не прототипа. Все
числа держи в src/config.js. Названия в игре — обобщённые (Скандинавская деревня,
Фьорды, Океанариум, Музей электронной музыки, Скандинавская столица, Автодром),
без реальных городов/артистов/брендов.
```
