# The Second One — бриф на прототип (вертикальный срез)

_Для разработки. Опирается на мастер-GDD «The Second One — дизайн-документ» (§14.1) и `setup.md`. Все числа — стартовая догадка для кручения на ощущениях, не финал._

## Цель

Ответить на главный вопрос проекта: **удерживать второе место — весело или бесит?** Один трек, одна петля цикла. Больше прототип не проверяет.

**Критерии успеха (из §14.1):**

- Игрок понимает цель за 10–15 секунд без объяснений.
- Делает несколько рестартов подряд по своей воле.
- Может объяснить, почему проиграл (первый / третий).
- Финиш читаем — видно, кто где, в последние секунды.

## Скоуп

**Входит:** одна трасса (архетип «Качели»), наклон-руль + газ + дрифт, один чемпион + 3 среднячка, окно серебра, тяжесть лидерства (визуал прожектора можно заглушкой), финишная зона, звёзды, один перк (зум финиша), церемония позора.

**НЕ входит (осознанно отложено):** случайные события и урон, банды и правила слипстрима, серебряный заряд и остальные перки, экономика/магазин, другие миры, мультиязычность и озвучка, мета и прогрессия. Слипстрим в прототип берём в упрощённом виде (только тяга за лидером), без «заряда».

## Управление (раскладка прототипа)

Ландшафт, две руки. Наклон — только руль. Правый палец — газ. Левый — дрифт (крупная кнопка); перк (зум) — одна маленькая кнопка над дрифтом. Автокалибровка нейтрали на старте гонки, мёртвая зона, ползунок чувствительности.

## Цикл и правила (минимум для прототипа)

- 5 машин: игрок + чемпион + 3 среднячка. HUD: позиция «2/5» + два разрыва (до лидера сверху, до 3-го снизу).
- Чемпион честно едет на победу и задаёт темп; среднячки создают трафик, в финишной зоне лезут снизу.
- Финишная зона (последний отрезок): рано тормозить — обгонят снизу (3-е), рвануть — станешь первым (проигрыш).
- **Звёзды:** 1★ — финишировал вторым; 2★ — вторым и ни разу не был первым (любой кадр носом впереди лидера снимает звезду); 3★ — «идеальное серебро» (носом впритык к лидеру на финише). Для прототипа звёзды независимые.
- Церемония: 2-е — сдержанная похвала; 1-е — «церемония позора»; 3+ — «отстал». Всё скипается, рестарт в один тап.

## Трасса «Качели» (архетип §10.1)

Чередование **красных** зон (риск стать первым — где чемпион слаб, легко вырваться) и **синих** (риск отстать) каждые 4–8 секунд. Последние 25% содержат минимум одну красную и одну синюю. Финиш — поворотом (последний дрифт выставляет точный разрыв). Профиль чемпиона раскладывается против трассы: где он слаб (повороты) — красная зона, где силён (прямые) — синяя.

Мир — пиксели; длина корпуса машины ≈ 40 px. Крутить в конфиге.

## ИИ (прототип)

- **Чемпион:** держит темп ~ на 4% быстрее среднего игрока по трассе; профиль «силён на прямых, слабее в поворотах» — в поворотах теряет больше, давая игроку окно вырваться. Rubber-band только вне экрана.
- **Среднячки (3):** едут около базовой скорости с разбросом ±5%, создают трафик; в финишной зоне +8% и давят снизу.

## Технические заметки

Стек по `setup.md`: Phaser 3 + Vite, проект `~/projects/game-prototype`, логика в `src/scenes/GameScene.js`. Наклон в вебе — DeviceOrientation (в APK позже — плагин Motion). Позиция — по прогрессу вдоль сплайна, не по координатам. Пересечение финиша — по переднему бамперу с интерполяцией внутри кадра. Все параметры выше — в один конфиг-объект, чтобы крутить без пересборки.

## Что делаем после прототипа

Если ядро «весело» — переходим к бете по §14.2 (тяжесть лидерства целиком, серебряный заряд, два слота перков, деревня целиком, фьорды с первым лидером, события и урон). Открытые вопросы (20 шт. в GDD) закрываем по ходу — большинство на ощущениях, а не на бумаге.
